Coffee_Sales_Analysis – Excel Data Analytics Project

Project Overview

- An end-to-end data analytics project using Microsoft Excel to analyze coffee sales performance and uncover business insights. The project focuses on exploring sales trends, product performance, customer purchasing behavior, and revenue patterns through data cleaning, analysis, and interactive dashboard development.

Tools & Technologies

- Microsoft Excel: Data analysis and dashboard development.

- Power Query: Data cleaning and transformation.

* Pivot Tables: Data summarization and analysis.

+ Pivot Charts: Data visualization.

+ Excel Formulas: Data calculations and analysis.

+ Slicers: Interactive dashboard filtering.

Project Workflow

- Data Loading: Imported and explored the coffee sales dataset.

- Data Cleaning: Handled missing values and inconsistent data.

* Data Transformation: Organized and prepared the data for analysis.

+ Data Analysis: Used Excel formulas and Pivot Tables to analyze sales performance.

+ Data Visualization: Created charts to identify sales trends and product performance.

+ Dashboard Development: Built an interactive Coffee Sales Dashboard using Pivot Charts and slicers.

Dashboard Analysis

The interactive dashboard provides insights into:

- Total sales and revenue trends over time.

- Sales distribution across countries.

* Top customers based on purchasing activity.

+ Monthly and yearly sales trends.
